Chisa · 主页背景与空内容定制版
================================
本版本以 Chisa-Shirone-No-Demo-Moments.zip 为基础继续修改：
- 使用你提供的图片 public/images/chisa-banner.jpg 作为桌面/手机主页背景；
- 删除全部已发布文章，包括此前添加的 Chisa 欢迎文章；不添加占位文章；
- 随笔保持空白；相册保持空白；保留文章、随笔、相册页面和日后新增内容的功能；
- 首页没有文章时显示简单欢迎卡片和项目展示入口；
- Chisa 名称、GitHub 头像及三个项目展示保持不变；
- 旧版演示背景图片已从本压缩包中移除。

注意：压缩包里没有演示文章和相册照片，不代表直接将文件上传 GitHub 后，
GitHub 仓库里的同名以外旧文件会自动删除。建议使用 Git 的完整替换方法。

建议使用 Windows Git Bash，在一个全新目录中：
1. git clone https://github.com/AsakiChisa/Shirone-homepage.git
2. cd Shirone-homepage
3. git switch -c chisa-clean-home
4. git rm -r -- .
   （只在刚克隆的干净仓库和新分支操作！此命令暂存删除全部旧版受版本控制文件，
    不会删除 .git；随后需要解压本完整源码包恢复全部新文件。）
5. 将本压缩包【内部所有文件和目录】直接解压/复制到当前仓库根目录，
   不要再多套一层文件夹，不要把原 ZIP 放进仓库。
6. git add -A
7. git commit -m "Customize Chisa homepage and remove demo content"
8. git push -u origin chisa-clean-home
9. 在 GitHub 上创建 PR，先查看 Cloudflare 非生产分支构建/预览结果，
   确认无误后合并到 main，正式域名 chisa.uk 会按照当前部署设置更新。

如果本地有未备份的私人改动，不要使用上述覆盖流程。先另存原文件再对比。
网站开启外部内容仓模式时，外部内容仓可能重新注入文章；要保持当前本地内容模式。

以后发表文章：在 src/content/posts/ 添加 Markdown 或 MDX 文件。
以后发表随笔：在 src/content/moments/ 添加对应文件。
以后添加相册：按 public/images/albums/README.md 的说明添加文件。
更换背景：替换 public/images/chisa-banner.jpg，保持文件名不变即可。
